# Anotomía

App de notas para estudiantes: pizarrón infinito, páginas A4 y tarjetas, con escritura a mano y con teclado.
Todo se guarda en el dispositivo (IndexedDB); no hay servidor ni cuenta.

## Uso en desarrollo

```
npm install
npm run dev      # http://localhost:3000 (y por red local desde la tablet)
npm test         # pruebas automáticas
npm run build    # versión de producción en dist/
```

Estado del proyecto y decisiones: ver `ESTADO.md`.
